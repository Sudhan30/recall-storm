All videos are 1920x1080, 30 fps, H.264 (high) + AAC 48 kHz stereo, with captions burned in. Each `<video>.shots.json` lists
every shot (start, duration, kind, source, on-screen label) and every narration line as spoken.

## What is AI-generated and what is real

Every shot carries an on-screen label.

| Label on screen | Source | How it was made |
|---|---|---|
| **AI-generated illustration** (magenta) | `raw/veo/*.mp4` | `gen_veo.py`. Veo 3.1 (`veo-3.1-*-generate-preview`) returns *404 "no longer available"* on this key and points to `gemini-omni-1.1-flash` (Interactions API), so that model made the shots. Prompts ask for a generic big-box store / generic distribution center with no logos, brand names, readable signage, or recognizable faces. Six 8 s clips: `store_night`, `aisle_pull`, `scanner_shelf`, `dc_trucks`, `dc_interior`, `highway_trucks`. The generator's own audio is discarded. |
| **REAL CAPTURE · project viewer** | `raw/cap/*` | `capture_viewer.py` drives the team's viewer (`viewer/`) in headless Chromium (Playwright, Metal) with keys 1-5, Space, clicks and drags. A fake page clock steps 1/30 s per frame, so motion is smooth and runs at the viewer's own replay speed. Nothing in the page is modified. The data is a fresh rebuild (`snapshot_viewer.py`, 11:58) because the repo's `viewer/data/live/` was built at 11:31, mid-expansion. |
| **REAL CAPTURE · viewer evidence cards** | `raw/cap/card{1,2,3}.png` | Element screenshots of the viewer's "Evidence: demo trio" cards (WM1563). Product names and brands in the cards are USDA FoodData Central data, shown as-is. |
| **REAL CAPTURE · terminal output** | `assets/term/*.txt` | Real stdout from commands run at the event, typed onto a terminal frame. `$SCRATCH` stands for the scratch directory the run wrote to (the commands' `--out`/`--report` pointed there, so the repo's `out/` and `reports/` were not touched). `verify_plan` output matches `reports/core*_plan.json`. |
| **OURS · rendered from reports/accept_\*.xml** | `build.py` `table_img` | The matched-packages table, drawn from the JUnit XML numbers. |
| Title / end / `[v2 numbers pending]` cards | `build.py` | Text only. |

Narration: `gemini-3.8-flash-tts`, voice Charon (`gen_tts.py`). One WAV per line in `assets/vo/`, cached by text hash.

## Numbers

`numbers.json` is generated by `make_numbers.py`. It reads every number from its file (`reports/*_plan.json`,
`reports/expansion_code.json`, `reports/expansion_seams.json`, `reports/accept_*.xml`, `runs/expansion/hops.jsonl`,
`patches/LOG.md`, `patches/agent/LOG.jsonl`, `baselines/README.md`) and records the file and field. Narration in `edl.py`
uses `{key}` placeholders, so a spoken number cannot drift from its source. Special cases:

- `exp1.cost_usd` ($3.56) is **derived**. It uses the viewer's formula over `runs/expansion/hops.jsonl`: $10/1M × (visible + thinking) + $2/1M × the sum of prompt tokens over hops (506,992). The narration says "about $3.56".
- `live.longest_tests_passed` (9) comes from a live pytest run of the code wall's longest passing call (`assets/term/exp_longest_test.txt`). It is real output but not one of the report files. The narration only says "They pass"; the 9 is visible in the terminal shot.
- Rounding: precision/recall are rounded to 3 dp (0.9465 → 0.947, which matches the viewer).
- `exp2.*` keys are `null` with `"pending": true` until `runs/expansion_v2/hops.jsonl` ends with `STOP` and `reports/expansion_v2_{seams,code}.json` exist.

## Rebuild

Needs ffmpeg at `/opt/homebrew/bin/ffmpeg` and a Python with Pillow + numpy for `build.py`, plus Playwright for
`capture_viewer.py`. The session used a scratch venv:
`python3 -m venv /tmp/pw && /tmp/pw/bin/pip install playwright pillow numpy` (Chromium was already in `~/Library/Caches/ms-playwright`).
`videos/raw/` (AI clips, captures, build intermediates) is gitignored, so it only exists on the machine that made it.

```bash
python3 videos/make_numbers.py                                   # numbers.json
set -a && source .env && set +a && .venv/bin/python videos/gen_tts.py backup_core demo_full_draft one_minute
/tmp/pw/bin/python videos/build.py backup_core demo_full_draft one_minute
```

Only narration lines whose filled text changed are re-synthesized, and a build takes about 1-2.5 min per video.

### Final cut with expansion v2 numbers (after ~1:45 PM)

```bash
python3 videos/make_numbers.py                     # exp2.* fill in from runs/expansion_v2 + reports/expansion_v2_*.json
.venv/bin/python videos/snapshot_viewer.py /tmp/rs_snap && (python3 -m http.server -d /tmp/rs_snap 8001 &)
/tmp/pw/bin/python videos/capture_viewer.py --run expansion_v2 --suffix _v2 hops code gallery
#   -> raw/cap/hops_expansion_v2.png, codewall_v2.mp4, codewall_longest_v2.png, gallery_expansion_v2.png
# Look at raw/cap/codewall_longest_v2.png, put its two files in LONGEST["expansion_v2"] in make_numbers.py,
# run their tests and save the output as assets/term/exp_longest_test_v2.txt (same format as exp_longest_test.txt):
#   PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=gen/<v2 gen dir>:. .venv/bin/python -m pytest <a> <b> -v -p no:cacheprovider
python3 videos/make_numbers.py
set -a && source .env && set +a && .venv/bin/python videos/gen_tts.py demo_full_final one_minute_final
/tmp/pw/bin/python videos/build.py demo_full_final one_minute_final
```

Any segment still missing a number or an asset renders a `[v2 numbers pending]` card and lists what it lacks in
`<video>.shots.json` (`segments[].pending`). Nothing is guessed. If the v2 gen dir or report names differ from
`expansion_v2`, change the `hops("expansion_v2", ...)` / `code_report("expansion_v2", ...)` calls in `make_numbers.py`.

## Script notes (deviations from BUILD.md section 14, on purpose)

- Hook: "about 300 California ... locations" became **"20 California Walmart and Sam's Club locations"**. 300 is not in any report; 20 is `records.store_playbook` in `reports/core_patched_plan.json`. In the draft, "a 760K-token version" is spoken as the v1 number (254,377). The final cut uses `{exp2.visible}`.
- Section 4: "the right way to run a **recall**" became "the right way to run a **compliance pull**" (hard rule: never "recall" for Red No. 3).
- The openFDA lot-code scenario is not shown (G5 status unknown).
- Never said: "Walmart data", "5,000 stores", "1M tokens in one request", "no other model can".

## API usage

Every call is in `usage.jsonl`. Totals at the time of the last commit are in the commit message and the summary below.

| Model | Calls | Output |
|---|---|---|
| `veo-3.1-fast-generate-preview` | 6 | 0 (404, model retired; not billed) |
| `gemini-omni-1.1-flash` (video) | 6 | 48 s of video, 417,024 output tokens |
| `gemini-3.8-flash-tts` | see `usage.jsonl` | ~22K audio tokens |
| `gemini-3.5-flash` | 1 | transcription check of one narration take |

Cost: TTS and the one text call are well under $1. Video pricing for `gemini-omni-1.1-flash` is not listed in the API
response. At Veo 3.1 per-second list rates ($0.15/s Fast to $0.40/s standard), 48 s comes to **$7-$19**, so the
total is under ~$20, inside the $40 budget.
